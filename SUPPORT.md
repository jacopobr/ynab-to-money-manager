# Support

Use [GitHub Issues](https://github.com/jacopobr/ynab-to-money-manager/issues) for reproducible bugs and feature requests. The project is community-maintained, so response times are not guaranteed.

Before opening an issue:

1. Read the README and the help sections inside the converter.
2. Confirm the source file is a transaction-level YNAB export.
3. Try the built-in small example.
4. Run the latest version from `main`.

Never attach real financial files to a public issue. Replace names, amounts, dates, payees, account numbers, and balances with invented values, then reduce the file to the smallest example that still reproduces the problem.

For security or privacy vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
